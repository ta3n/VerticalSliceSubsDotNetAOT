## Vertical Slice Subscriptions ✨

**This project contains a sample ASP.NET Core app. This app is an example of the article I produced for the Telerik Blog (telerik.com/blogs)**

Vertical Slice Subscriptions is a sample .NET project that demonstrates how **Vertical Slice Architecture** is useful for:

- ✅ Clean and explicit model of the project architecture
- 🛠️ Facilitates maintenance
- 🚀 Separation by functionalities (use cases)

### 📦 Technologies Used

- .NET 10
- ASP.NET Core
- EF Core
- In-memory database
- C#
- Web API
- Vertical Slice Architecture
